# Bytes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Keep task evidence and rulings here.

**Goal:** Process arbitrary binary values and files with a distinct typed Bytes
value through Core, STE, VM and native code.

**Architecture:** Shared pure no_std byte engine; typed action/function adapters;
existing file grants and filesystem helpers gain explicit binary modes.

**Tech Stack:** Rust2024 with no dependencies, direct Linux x86-64 ELF and existing
embedded runtime; independent Python byte oracle.

**Spec:** [Bytes design](../specs/2026-10-11-bytes-design.md).

## Global constraints

- Shared workspace, .git read-only; preserve prior work, no commits/worktrees.
- Bytes canonical transport hex: plus lowercase even hex; raw maximum1,048,576,
  canonical maximum2,097,156. Empty transport hex: costs4 when computed.
- Charge canonical Bytes results/returns to shared67,108,864 List/Json arena;
  preserve separate Text rules and atomic publication, borrow arguments for free.
- Exact engine ABI72/16, kinds0..11 and statuses0..6 from spec.
- Ten pure byte operations; two binary file operations; no implicit conversions.
- BYTES recovery index13, any16383; BYTES-LIMIT fatal, old indices unchanged.
- Existing host APIs/grants remain compatible; no new external dependency.
- Workers own disjoint files and must not spawn agents.

## Review focus

1. Hex transport versus raw value size, including literals larger than Text and
   conversions crossing only the Text limit; no accidental UTF-8 acceptance.
2. Inputs/outputs alias through nested and recursive functions; failed operations
   preserve destinations/counters and successful prior results remain valid.
3. Invalid source and failing index/value expressions: specified validation order
   stays identical on VM/native and whole-program verification rejects dead code.
4. Shared Bytes/List/Json allocation budget cannot be bypassed via returns or files;
   different producer error categories remain intentional and tested.
5. Bytes file writes validate before truncation and grants before data; invalid
   bindings, special files, short transfer/error paths preserve authority/cleanup.
